# Braxis MCP Server - Model Context Protocol Integration

**Braxis v3.0** now includes a fully-functional MCP (Model Context Protocol) server that exposes all 6 strategic extractors as Claude tools.

---

## Overview

The Braxis MCP Server allows Claude to:
- 🔍 Analyze repositories directly
- 📊 Extract AI context patterns
- 📝 Generate AGENTS.md files
- 🎯 Calculate readiness scores
- 🤖 Provide AI-optimized guidance

**All without leaving a Claude conversation.**

---

## Quick Start

### 1. Install

```bash
# From PyPI
pip install braxis

# Or from GitHub
git clone https://github.com/jaykrishna316/braxis
cd braxis
pip install -e .
```

### 2. Configure Claude

Add to `~/.claude/claude-mcp.json`:

```json
{
  "mcp_servers": {
    "braxis": {
      "command": "python",
      "args": ["-m", "braxis.mcp_stdio"],
      "env": {}
    }
  }
}
```

### 3. Restart Claude

Done! Braxis tools are now available.

### 4. Use in Claude

**Example conversation:**

```
User: Analyze /home/user/my-project and tell me its AI readiness

Claude will use Braxis to:
1. Extract all 6 pattern types
2. Calculate readiness score
3. Provide recommendations
```

### 2. `extract_patterns`

Extract specific pattern type.

**Usage in Claude:**
```
"Extract code generation patterns from /path/to/project"
```

**Pattern types:**
- `product_authority` - Product guarantees, contracts
- `architectural_constraints` - Breaking changes, critical rules
- `code_generation` - Generated files, providers
- `multi_variant` - Twins, platforms, auth
- `agent_policy` - Policies, sentiment
- `monorepo_subsystem` - Structure, per-package guidance

**Example:**
```json
{
  "pattern_type": "code_generation",
  "repo_path": "/path/to/project",
  "extraction": {
    "found": true,
    "providers": ["stainless", "openapi"],
    "generated_files": ["src/generated/client.py", "src/generated/types.py"],
    "ownership_map": {
      "src/generated/": "generated",
      "src/lib/": "hand-written"
    },
    "merge_strategies": {
      "stainless": "Keep local changes, fix in generator"
    }
  }
}
```

## Protocol Details

### Message Format

Braxis implements the **MCP v2024-11-05 protocol** over stdio.

**Request:**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "analyze_repository",
    "arguments": {
      "repo_path": "/path/to/repository"
    }
  }
}
```

**Response:**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{...extracted data...}"
      }
    ]
  }
}
```

### Standard Methods

- `initialize` - Initialize protocol connection
- `tools/list` - List available tools
- `tools/call` - Call a tool with arguments
- `completion/complete` - Text completion (optional)

## Architecture

### MCP Server Components

```
BraxisServer (mcp_server.py)
├── ProductAuthorityExtractor
├── ArchitecturalConstraintsExtractor
├── CodeGenerationExtractor
├── MultiVariantExtractor
├── AgentPolicyExtractor
└── MonorepoSubsystemExtractor

MCPHandler (mcp_stdio.py)
├── initialize()
├── list_tools()
└── call_tool()

Entry Point (__main__.py)
└── "python -m braxis.mcp_stdio"
```

### Data Flow

```
Claude
  ↓
[MCP Protocol over stdio]
  ↓
BraxisServer
  ↓
[6 Extractors]
  ↓
Pattern Detection
  ↓
Return JSON
  ↓
Claude displays results
```

## Troubleshooting

### Issue: "module not found: braxis.mcp_stdio"

**Solution:** Ensure Braxis is installed:
```bash
pip install -e .
```

### Issue: MCP server doesn't appear in Claude

**Solution:** Verify Claude config:
```bash
cat ~/.claude/claude-mcp.json
```

Should show:
```json
{
  "mcp_servers": {
    "braxis": {
      "command": "python",
      "args": ["-m", "braxis.mcp_stdio"]
    }
  }
}
```

### Issue: "Cannot read repository: Permission denied"

**Solution:** Check file permissions:
```bash
ls -la /path/to/repository
```

Repository must be readable.

### Issue: "No documentation found"

**Solution:** Repository needs README.md or CONTRIBUTING.md:
```bash
ls -la /path/to/repository/*.md
```
